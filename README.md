

### Project Name : Login Page

এটি HTML এবং CSS ব্যবহার করে তৈরি একটি Login Page Design Project। এই প্রজেক্টে HTML-এর বিভিন্ন Tag ব্যবহার করে Login Form-এর Structure তৈরি করেছি এবং CSS ব্যবহার করে Form-এর Design, Layout, Spacing, Color ও অন্যান্য Style নির্ধারণ করেছি।

### Technologies Used

- HTML5
- CSS3
- Google Fonts

### HTML Tags Explanation

HTML Tag হলো HTML-এর এমন কিছু নির্দিষ্ট Keyword বা নির্দেশনা, যার মাধ্যমে ওয়েবপেজের বিভিন্ন উপাদান তৈরি ও সাজানো হয়। প্রতিটি Tag ব্রাউজারকে জানায় ওয়েবপেজের কোন অংশে কী ধরনের Content থাকবে। নিচে এই প্রজেক্টে ব্যবহার করা HTML Tag-গুলোর কাজ ব্যাখ্যা করা হলো।

HTML Tag          |                         কাজ   

1. `<!DOCTYPE html>` এটি HTML5 Document Type Declaration। এটি ব্রাউজারকে জানায় যে ডকুমেন্টটি HTML5 ব্যবহার করে তৈরি করা হয়েছে।

2. `<html>` এটি HTML Document-এর Root Tag। এটি সম্পূর্ণ HTML ডকুমেন্টের মূল অংশ হিসেবে কাজ করে।

3. `<head>` এটি HTML Document-এর Head Section। এখানে ওয়েবপেজের প্রয়োজনীয় তথ্য, Metadata, Title এবং External Resource যুক্ত করা হয়।

4. `<meta>` এটি HTML-এর Metadata Tag। এটি ওয়েবপেজ সম্পর্কে বিভিন্ন তথ্য যেমন Character Encoding এবং Viewport নির্ধারণ করতে ব্যবহৃত হয়।

5. `<title>` এটি HTML-এর Title Tag। এটি ব্রাউজারের Tab-এ ওয়েবপেজের নাম প্রদর্শন করে।

6. `<link>` এটি HTML-এর Link Tag। এটি HTML Document-এর সঙ্গে External CSS File, Google Fonts এবং অন্যান্য Resource যুক্ত করতে ব্যবহৃত হয়।

7. `<body>` এটি HTML Document-এর Body Tag। এখানে ওয়েবপেজের দৃশ্যমান সব Content রাখা হয়।

8. `<div>` এটি HTML-এর Division Tag। এটি ওয়েবপেজের বিভিন্ন Element-কে আলাদা Group বা Container-এর মধ্যে রাখতে ব্যবহৃত হয়।

9. `<header>` এটি HTML-এর Header Tag। এটি কোনো Section বা Content-এর শিরোনাম অথবা পরিচিতিমূলক অংশ রাখতে ব্যবহৃত হয়।

10. `<input>` এটি HTML-এর Input Tag। এটি ব্যবহারকারীর কাছ থেকে Email, Password এবং অন্যান্য তথ্য নেওয়ার জন্য ব্যবহৃত হয়।

11. `<label>` এটি HTML-এর Label Tag। এটি Input Field বা Checkbox-এর পরিচিতি বা নাম প্রদর্শন করতে ব্যবহৃত হয়।

12. `<section>` এটি HTML-এর Section Tag। এটি ওয়েবপেজের সম্পর্কিত Content-কে একটি আলাদা Section বা অংশে সাজাতে ব্যবহৃত হয়।

13. `<a>` এটি HTML-এর Anchor Tag। এটি ওয়েবপেজে Hyperlink বা Link তৈরি করতে ব্যবহৃত হয়, যার মাধ্যমে এক পেজ থেকে অন্য পেজে বা অন্য ওয়েবসাইটে যাওয়া যায়।

14. `<button>` এটি HTML-এর Button Tag। এটি ওয়েবপেজে একটি Clickable Button তৈরি করতে ব্যবহৃত হয়, যার মাধ্যমে ব্যবহারকারীর কাছ থেকে কোনো Action নেওয়া যায়।

15. `<p>` এটি HTML-এর Paragraph Tag। এটি ওয়েবপেজে সাধারণ লেখা বা Paragraph প্রদর্শন করতে ব্যবহৃত হয়।

### About

এই প্রজেক্টটি HTML ও CSS শেখার অংশ হিসেবে তৈরি করেছি। এখানে HTML-এর বিভিন্ন Tag এবং Attribute ব্যবহার করে Login Page-এর Structure তৈরি করেছি। পাশাপাশি CSS-এর বিভিন্ন Property ব্যবহার করে Layout, Alignment, Spacing, Color, Shadow এবং Hover Effect যুক্ত করেছি।
